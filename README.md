# Netflix Clone 🎬

A pixel-perfect, fully responsive clone of the Netflix landing page built with semantic HTML5 and modern CSS3. This project replicates the UI/UX of Netflix to showcase frontend development and responsive design skills.

### **Features**
- **Responsive Design**: Works on mobile, tablet, and desktop using CSS Grid + Flexbox
- **Pixel-Perfect UI**: Matched original Netflix layout, typography, and color scheme
- **CSS Animations**: Hover effects on cards, buttons, and nav elements for interactivity
- **Semantic HTML5**: Clean, accessible markup for SEO and screen readers

### **Tech Stack**
- **HTML5** - Structure and content
- **CSS3** - Styling, animations, Grid, Flexbox

### **Run Locally**
1. Clone the repo: `git clone https://github.com/ShehreenFarooq/Netflix-Clone-Website.git`
2. Open `index.html` in your browser
